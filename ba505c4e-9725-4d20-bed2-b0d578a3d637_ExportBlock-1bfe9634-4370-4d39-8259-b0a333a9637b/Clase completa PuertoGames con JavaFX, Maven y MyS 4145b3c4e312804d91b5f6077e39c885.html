1. Problemática que resolveremos

PuertoGames es una tienda que comercializa videojuegos físicos y digitales. Necesita una aplicación que permita registrar, consultar, modificar y eliminar videojuegos, almacenando permanentemente la información en MySQL.

Las reglas de negocio serán:

TipoPrecio final
FísicoPrecio base + $5.000
DigitalPrecio base con 10 % de descuento

También validaremos que el código y el nombre sean obligatorios y que el precio base sea mayor que cero.

2. Paso a paso desde cero

Paso 1. Preparar MySQL

Con XAMPP, inicia MySQL y Apache, después entra a http://localhost/phpmyadmin. Con Laragon, inicia el servidor y abre su administrador de base de datos.

Selecciona la pestaña SQL y ejecuta este código, que también está incluido en puertogames.sql.

-- Crea la base de datos si no existe.
CREATE DATABASE IF NOT EXISTS puertogames
CHARACTER SET utf8mb4;

-- Selecciona la base de datos.
USE puertogames;

-- Crea la tabla de videojuegos.
CREATE TABLE IF NOT EXISTS videojuegos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    codigo VARCHAR(20) NOT NULL UNIQUE,
    nombre VARCHAR(100) NOT NULL,
    precio_base INT NOT NULL,
    tipo ENUM('FISICO', 'DIGITAL') NOT NULL,
    CHECK (precio_base > 0)
);

-- Consulta los registros almacenados.
SELECT * FROM videojuegos;

La columna id identifica cada videojuego, codigo no permite duplicados y tipo solamente acepta FISICO o DIGITAL.

4. Modelo: herencia y polimorfismo

Primero crearemos las clases que representan los videojuegos. Estos archivos no necesitan conocer JavaFX ni MySQL.

Archivo 1 — Videojuego.java


package cl.duoc.puertogames.model;

// Clase padre abstracta: concentra los atributos comunes.
public abstract class Videojuego {

    // Identificador y precio base del videojuego.
    private final int id, precioBase;

    // Código y nombre del videojuego.
    private final String codigo, nombre;

    // Constructor utilizado por las clases hijas.
    public Videojuego(int id, String codigo, String nombre, int precioBase) {

        // Valida que el código y el nombre no estén vacíos.
        if (codigo == null || codigo.isBlank() || nombre == null || nombre.isBlank()) {
            throw new IllegalArgumentException("Código y nombre son obligatorios.");
        }

        // Valida que el precio base sea mayor que cero.
        if (precioBase <= 0) {
            throw new IllegalArgumentException("El precio debe ser mayor que cero.");
        }

        // Guarda los valores recibidos en los atributos.
        this.id = id;
        this.codigo = codigo.trim();
        this.nombre = nombre.trim();
        this.precioBase = precioBase;
    }

    // Getters: permiten consultar los atributos privados.
    public int getId() { return id; }
    public String getCodigo() { return codigo; }
    public String getNombre() { return nombre; }
    public int getPrecioBase() { return precioBase; }

    // Las clases hijas implementan estos métodos.
    public abstract String getTipo();
    public abstract int getPrecioFinal();

    // Indica cómo se mostrará el videojuego en ListView.
    @Override
    public String toString() {
        return codigo + " - " + nombre + " - " + getTipo() + " - $" + getPrecioFinal();
    }
}

Para explicar: Videojuego es abstracta porque no queremos crear un videojuego genérico. Cada videojuego será físico o digital. Los atributos private están encapsulados y los getters permiten acceder a ellos.

El método toString() es importante: JavaFX lo utilizará automáticamente para mostrar los videojuegos dentro de ListView, evitando configurar columnas como en TableView.

5. Conexión a MySQL

Archivo 4 — Conexion.java

Este archivo configura la comunicación con MySQL. No realiza operaciones CRUD.


package cl.duoc.puertogames.config;

// Importamos las clases necesarias para conectarnos a MySQL.
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;

// Centraliza la configuración de la base de datos.
public class Conexion {

    // Dirección del servidor y nombre de la base de datos.
    private static final String URL =
            "jdbc:mysql://localhost:3306/puertogames?useSSL=false";

    // Usuario con el que nos conectaremos a MySQL.
    private static final String USUARIO = "root";

    // Contraseña del usuario. Vacía para este ejemplo local.
    private static final String CLAVE = "";

    // Método que abre una conexión con la base de datos.
    public static Connection abrir() throws SQLException {

        // Intenta conectarse y devuelve una conexión abierta.
        return DriverManager.getConnection(URL, USUARIO, CLAVE);
    }
}

Analogía para los alumnos: Conexion.java es la puerta de acceso a la cocina del restaurante. Abre la comunicación, mientras que el DAO actúa como el mesero que lleva y trae información.

Los valores root y contraseña vacía corresponden únicamente a una configuración local de ejemplo. Deben ajustarse si MySQL utiliza otras credenciales.

6. Capa DAO — Operaciones CRUD con MySQL

Archivo 5 — VideojuegoMySQLDAO.java

Esta es la clase que más conviene profundizar en la primera sesión. Aquí los estudiantes aprenden cómo Java conversa con MySQL utilizando JDBC.

En lugar de tener cuatro métodos distintos, trabajaremos con tres: listar(), guardar() y eliminar().


package cl.duoc.puertogames.dao;

import cl.duoc.puertogames.config.Conexion;
import cl.duoc.puertogames.model.*;
import java.sql.*;
import java.util.*;

// DAO: concentra las consultas SQL del proyecto.
public class VideojuegoMySQLDAO {

    // READ: obtiene todos los registros de MySQL.
    public List<Videojuego> listar() {

        // Lista donde guardaremos los videojuegos encontrados.
        List<Videojuego> juegos = new ArrayList<>();

        // Abre la conexión y ejecuta una consulta SELECT.
        // try-with-resources cierra los recursos automáticamente.
        try (Connection cn = Conexion.abrir();
        
			       // PreparedStatement representa la instrucción SQL preparada.
             PreparedStatement ps = cn.prepareStatement("SELECT * FROM videojuegos ORDER BY id");
             
             // ResultSet guarda el resultado para recorrer las filas obtenidas.
             ResultSet rs = ps.executeQuery()) {

            // Recorre los videojuegos encontrados, next=fila por fila.
            while (rs.next()) {

                // Obtiene los datos de las columnas MySQL.
                int id = rs.getInt("id");
                String codigo = rs.getString("codigo");
                String nombre = rs.getString("nombre");
                int precio = rs.getInt("precio_base");

                // Comprueba si el videojuego es físico.
                if ("FISICO".equals(rs.getString("tipo"))) {
                

                    // Crea un juego físico y lo agrega a la lista.
                    juegos.add(new JuegoFisico(id, codigo, nombre, precio));
                    

                } else {

                    // Si no es físico, crea un juego digital.
                    juegos.add(new JuegoDigital(id, codigo, nombre, precio));
                }
            }

        // Captura los errores relacionados con MySQL.
        } catch (SQLException e) {
            throw new RuntimeException("Error al listar: " + e.getMessage(), e);
        }

        // Devuelve todos los videojuegos recuperados.
        return juegos;
    }
    
    
    
    

    // CREATE / UPDATE: registra o modifica un videojuego.
    public void guardar(Videojuego j) {

        // Consulta SQL para agregar un nuevo videojuego.
        String sql = "INSERT INTO videojuegos(codigo,nombre,precio_base,tipo) VALUES(?,?,?,?)";

        // Si el videojuego tiene ID, significa que queremos editarlo.
        if (j.getId() != 0) {

            // Consulta SQL para modificar el registro existente.
            sql = "UPDATE videojuegos SET codigo=?,nombre=?,precio_base=?,tipo=? WHERE id=?";
        }

        // Abre la conexión y prepara la consulta SQL.
        try (Connection cn = Conexion.abrir();
             PreparedStatement ps = cn.prepareStatement(sql)) {

            // Reemplaza los signos ? con los datos del videojuego.
            ps.setString(1, j.getCodigo());
            ps.setString(2, j.getNombre());
            ps.setInt(3, j.getPrecioBase());
            ps.setString(4, j.getTipo());

      // Si estamos editando, también enviamos su ID.
     // Comprueba si el videojuego tiene un ID diferente de cero.
    // Si tiene ID, significa que estamos actualizando un registro.
            if (j.getId() != 0) {
                ps.setInt(5, j.getId());
            }

            // Ejecuta INSERT o UPDATE en MySQL.
            int filas = ps.executeUpdate();

            // Comprueba que la operación afectó un registro.
             // Comprueba si la consulta no afectó ningún registro.

            if (filas == 0) {
                throw new RuntimeException("No se encontró el videojuego.");
            }
            

        // Captura errores de conexión o ejecución SQL.
        } catch (SQLException e) {
            throw new RuntimeException("Error al guardar: " + e.getMessage(), e);
        }
    }
    
    

    // DELETE: elimina el videojuego mediante su ID.
    public void eliminar(int id) {

        // Prepara la consulta DELETE.
        try (Connection cn = Conexion.abrir();
             PreparedStatement ps = cn.prepareStatement(
                     "DELETE FROM videojuegos WHERE id=?")) {

            // Reemplaza el signo ? por el ID del videojuego.
             // Asigna el ID recibido al primer signo ?.
            // Por ejemplo, si id = 3, buscamos eliminar el registro 3.
            // Asigna el ID al primer signo ?.
            ps.setInt(1, id);
            

             // Ejecuta la instrucción DELETE en MySQL.
            // Devuelve cuántas filas fueron eliminadas.
            int filas = ps.executeUpdate();

            // Comprueba no s eliminó ningún registro.
            if (filas == 0) {
                throw new RuntimeException("No se encontró el videojuego.");
            }

        // Captura errores relacionados con MySQL.
        } catch (SQLException e) {
            throw new RuntimeException("Error al eliminar: " + e.getMessage(), e);
        }
    }
}

¿Qué deben comprender los estudiantes sobre este DAO?

El método listar() ejecuta SELECT, recorre las filas mediante ResultSet y transforma cada fila en un objeto Java.

El método guardar() toma una decisión sencilla:

if (j.getId() != 0) {
    // UPDATE: el videojuego ya existe.
} else {
    // INSERT: es un videojuego nuevo.
}

Y eliminar() necesita únicamente el ID para saber qué registro debe borrar.

Podemos explicar PreparedStatement como una plantilla SQL que tiene espacios reservados mediante ?. Después Java reemplaza esos espacios por los datos correctos usando setString() o setInt().

7. Controller — Conectar el formulario con MySQL

Archivo 6 — JuegoController.java

Este archivo maneja los botones y los campos del formulario. No escribe ninguna sentencia SQL, porque esa responsabilidad pertenece al DAO.


package cl.duoc.puertogames.controller;

import cl.duoc.puertogames.dao.VideojuegoMySQLDAO;
import cl.duoc.puertogames.model.*;
import javafx.fxml.FXML;
import javafx.scene.control.*;

// Controlador que recibe los eventos de la interfaz.
public class JuegoController {

    // ComboBox para elegir el tipo de videojuego.
    @FXML private ComboBox<String> tipo;

    // Campos para ingresar código, nombre y precio.
    @FXML private TextField codigo, nombre, precio;

    // Lista gráfica que mostrará los videojuegos.
    @FXML private ListView<Videojuego> lista;

    // Etiqueta que muestra mensajes al usuario.
    @FXML private Label mensaje;

    // Objeto DAO encargado de acceder a MySQL.
    private final VideojuegoMySQLDAO dao = new VideojuegoMySQLDAO();

    // Se ejecuta automáticamente cuando se abre la ventana.
    @FXML private void initialize() {

        // Agrega las opciones disponibles al ComboBox.
        tipo.getItems().addAll("FISICO", "DIGITAL");

        // Carga los videojuegos desde MySQL.
        try {
            cargar();
        } catch (RuntimeException e) {
            mensaje.setText(e.getMessage());
        }
    }

    // Consulta los videojuegos y actualiza la lista.
    private void cargar() {

        // Pide los datos al DAO y los coloca en ListView.
        lista.getItems().setAll(dao.listar());
    }

    // Se ejecuta cuando seleccionamos un juego de la lista.
    @FXML private void seleccionar() {

        // Obtiene el videojuego seleccionado.
        Videojuego j = lista.getSelectionModel().getSelectedItem();

        // Si no existe selección, termina el método.
        if (j == null) return;

        // Copia los datos del videojuego al formulario.
        tipo.setValue(j.getTipo());
        codigo.setText(j.getCodigo());
        nombre.setText(j.getNombre());

        // Convierte el precio entero en texto.
        precio.setText(String.valueOf(j.getPrecioBase()));
    }

    // Se ejecuta al presionar el botón Guardar.
    @FXML private void guardar() {

        // Captura errores al validar o guardar datos.
        try {

            // Comprueba que se haya seleccionado un tipo.
            if (tipo.getValue() == null) {
                mensaje.setText("Selecciona un tipo.");
                return;
            }

            // Convierte el precio escrito a número entero.
            int monto = Integer.parseInt(precio.getText().trim());

            // Obtiene el videojuego seleccionado, si existe.
            Videojuego seleccionado = lista.getSelectionModel().getSelectedItem();

            // ID 0 indica que registraremos un videojuego nuevo.
            int id = 0;

            // Si existe un juego seleccionado, conservamos su ID.
            if (seleccionado != null) {
                id = seleccionado.getId();
            }

   // Instancia de Videojiuego Variable que puede contener cualquiera de las clases hijas.
            Videojuego juego;

            // Crea un videojuego físico cuando corresponde.
            if ("FISICO".equals(tipo.getValue())) {
                juego = new JuegoFisico(id, codigo.getText(), nombre.getText(), monto);

            // En caso contrario, crea un videojuego digital.
            } else {
                juego = new JuegoDigital(id, codigo.getText(), nombre.getText(), monto);
            }

            // Envía el objeto al DAO para insertarlo o actualizarlo.
            dao.guardar(juego);

            // Consulta MySQL nuevamente para actualizar la lista.
            cargar();

            // Limpia los campos del formulario.
            limpiar();

            // Informa que la operación terminó correctamente.
            mensaje.setText("Videojuego guardado correctamente.");

        // Captura precios que no son números enteros.
        } catch (NumberFormatException e) {
            mensaje.setText("El precio debe ser un número entero.");

        // Captura errores del modelo o de MySQL.
        } catch (RuntimeException e) {
            mensaje.setText("Error: " + e.getMessage());
        }
    }

    // Se ejecuta al presionar el botón Eliminar.
    @FXML private void eliminar() {

        // Obtiene el videojuego seleccionado.
        Videojuego j = lista.getSelectionModel().getSelectedItem();

        // Comprueba que exista un videojuego seleccionado.
        if (j == null) {
            mensaje.setText("Selecciona un videojuego.");
            return;
        }

        // Intenta eliminar el videojuego.
        try {

            // Solicita al DAO borrar el registro mediante su ID.
            dao.eliminar(j.getId());

            // Vuelve a consultar los videojuegos de MySQL.
            cargar();

            // Limpia la información del formulario.
            limpiar();

            // Confirma que el videojuego fue eliminado.
            mensaje.setText("Videojuego eliminado.");

        // Muestra los errores ocurridos durante la eliminación.
        } catch (RuntimeException e) {
            mensaje.setText("Error: " + e.getMessage());
        }
    }

    // Limpia los campos y elimina la selección actual.
    @FXML private void limpiar() {

        // Quita la selección del videojuego.
        lista.getSelectionModel().clearSelection();

        // Limpia el ComboBox.
        tipo.setValue(null);

        // Borra todos los campos de texto.
        codigo.clear();
        nombre.clear();
        precio.clear();
    }
}

¿Por qué es más sencillo este Controller?

Todo se concentra en cinco acciones:

MétodoQué realiza
initialize()Prepara el ComboBox y carga los datos iniciales.
cargar()Consulta al DAO y actualiza ListView.
seleccionar()Copia los datos seleccionados al formulario.
guardar()Registra o actualiza un videojuego.
eliminar()Elimina el registro seleccionado.
limpiar()Restablece el formulario.

El único concepto que requiere especial atención es el ID: cuando no hay un videojuego seleccionado, utilizamos 0 para registrar; cuando existe uno seleccionado, utilizamos su ID real para actualizarlo.

Para explicar a los estudiantes: fx:id relaciona cada componente gráfico con una variable del controlador, mientras que onAction="#guardar" vincula el botón con el método guardar().

9. Clase principal — App.java

Archivo 8 — App.java

Este archivo es el punto de entrada de JavaFX.


package cl.duoc.puertogames;

import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.stage.Stage;

// Clase principal que inicia la aplicación JavaFX.
public class App extends Application {

    // JavaFX ejecuta este método para crear la ventana.
    @Override
    public void start(Stage stage) throws Exception {

        // Busca y carga el archivo FXML.
        Parent vista = FXMLLoader.load(App.class.getResource("main-view.fxml"));

        // Crea la escena con dimensiones de 900 x 450 píxeles.
        stage.setScene(new Scene(vista, 900, 450));

        // Establece el título de la ventana.
        stage.setTitle("PuertoGames - Catálogo de videojuegos");

        // Muestra la ventana.
        stage.show();
    }

    // Método principal que inicia JavaFX.
    public static void main(String[] args) {
        launch(args);
    }
}
